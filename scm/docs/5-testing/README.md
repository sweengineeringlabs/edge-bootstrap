> [← Back to Documentation Hub](../README.md)

**Audience**: Developers, architects

## WHAT

Test and benchmark reports for `edge-bootstrap` — results and analysis from exercising a running
`edge-bootstrap` process, not the process's own source.

## WHY

Records what was measured, how, and what it does and does not prove, so a later investigation
doesn't have to re-run the same experiment to answer the same question.
